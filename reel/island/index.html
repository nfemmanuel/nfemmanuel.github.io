What just happened, and how it would really work

1Action Button runs our Control (iOS 18 Controls API) — which is just one of our App Intents wearing a button.
2The intent starts a Live Activity — that's the only way into the Dynamic Island, and it fits: a fill session is a real ongoing activity with progress.
3Each tap on the island is a LiveActivityIntent button — it copies the next item without the app opening. Long-press expands the full session list.

The honest catches

Hardware-gated: Dynamic Island needs iPhone 14 Pro / any 15 or later; the Action Button needs 15 Pro / any 16 or later. The judge's crowd has this hardware; plenty of users don't — so it's a delight layer, never the only path.

Apple's guidance: the island is a status layer, not a launcher. The session framing (progress through N items) is what makes this legitimate rather than a hack.

Samsung twin: same idea maps to One UI — side-key double-press via RegiStar, and a Now Bar chip for the session. One shared concept, two native expressions.
