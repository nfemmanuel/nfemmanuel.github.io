Privacy Policy: nf-machine

Last updated: November 18, 2026

nf-machine is a personal tool that NF Emmanuel runs on NF's own computer. It uses Google sign-in (OAuth) to read and act on Google accounts that NF owns or that their owners have connected to it themselves. It is not offered to the public.

What data it uses

Only the Google account data covered by the permissions granted on Google's consent screen, and only to carry out the tasks the account owner set it up for.

Where the data goes

Data is processed and stored on NF's own computer. It is not sold, not shared with third parties, and not used for advertising.

Keeping and deleting data

You can remove nf-machine's access at any time at myaccount.google.com/permissions. To ask for any stored data to be deleted, contact NF through the links on nfemmanuel.com.

Google API Services

nf-machine's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.
